# City Generation
The `CityGenerator` (`src/procgen/CityGenerator.ts`) is the primary coordinator for assembling the skyline. It ties together the [[Biome System]] and [[Chunk System]] to emit layered landscapes and cityscapes.

## City DNA
Each city instance gets a `CityDNA` profile generated via [[Deterministic Randomness]]. This acts as the master tuning variables for the run:
- **Density**: Range [0.4, 0.9] - Dictates building frequency.
- **Greenery**: Range [0.1, 0.8] - Dictates tree frequency.
- **Building Height**: Range [0.8, 1.2] - Scales all building heights.

## Generation Loop
The main `generate()` method observes the camera X position. As the player scrolls, it calculates the required draw distance per layer. If a layer lacks sufficient coverage (tracked via an internal array of last X coordinates), it continuously requests chunks to be generated by the [[Chunk System]] until the layer is fully populated beyond the viewport boundary.

Colors, roofs, and materials are chosen according to the current active biome (see [[Biome System]]).

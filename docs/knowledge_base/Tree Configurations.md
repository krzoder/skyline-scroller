# Tree Configurations

Trees add natural variation to the environment. They are generated by `CityGenerator.ts` when dictated by the greenery stat in the [[City Generation]] DNA, using constraints from `TreeConfig.ts` and drawing logic in `Tree.ts`.

## Configuration Parameters
Each tree type has strict constraints defined in `DEFAULT_TREE_CONFIG`:
- **Enabled**: Boolean toggle.
- **Biomes**: Array defining valid biomes (tied to [[Biome Mechanics]]). For example, `cactus` only spawns in `desert`; `pine` in `forest` and `tundra`.
- **Min/Max Height**: Defines the parametric vertical scale.
- **Flower Chance**: Specifically used by cacti to probabilistically spawn a flower.

## Drawing Logic
Like buildings (see [[Building Configuration]]), trees cache their graphics to an offscreen canvas.
- `sequoia`: Draws a trunk and loops through 8 layers of progressively wider green ellipses.
- `pine`: Iterates through overlapping jagged triangles pointing upwards.
- `oak`: Plots a set of 5 clustered circles ("puffs") to simulate a broad leafy crown.
- `bush` / `hedge`: Utilizes simple arcs or rounded rectangles to mimic ground-level foliage.
- `cactus`: Draws a main green stem and offset arm rectangles. If `hasFlower` is true, a bright pink dot is plotted on the top of either the left or right arm.
